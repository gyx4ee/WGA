WGA UI Assets v2
================

Complete UI asset package for WinSys Guardian Advanced PySide6 redesign.

Folders:
- reference: full UI reference
- logo: WGA logo/symbol
- backgrounds: hero artwork
- navigation: sidebar icons
- tools: dashboard tool icons
- system: hardware/status icons
- actions: quick action icons
- status: state/navigation symbols

All generated icons are transparent PNG, 256x256, intended for use in Qt/PySide6.
Cards, buttons, panels, text, progress indicators and layouts should be implemented as real Qt widgets/QSS, not raster images.

Recommended icon display sizes:
- sidebar: 20-24 px
- tool cards: 40-56 px
- system status: 24-36 px
- quick actions: 28-40 px
